¿Qué 2 tareas del backlog harías primero?

1. Como ciudadano quiero registrar una incidencia para dejar evidencia de una situación que afecta a mi comunidad.

2. Como coordinador quiero recibir una alerta en Telegram cuando se genere un nuevo reporte para poder revisarlo oportunamente.


¿Por qué son las más importantes?

Son las más importantes porque permiten iniciar el proceso de gestión de reportes. Primero se necesita que los ciudadanos puedan registrar sus casos y luego que el equipo encargado pueda recibir las notificaciones para atenderlos rápidamente.


¿Qué significa para ti que una tarea esté “terminada”?

Significa que la tarea cumple con el objetivo definido, funciona correctamente y está lista para ser utilizada por los usuarios.


Definición simple de terminado:

Una tarea está terminada cuando:

- Funciona correctamente según lo solicitado.
- Fue probada y no presenta errores importantes.
- Quedó registrada en Git con sus cambios guardados.
